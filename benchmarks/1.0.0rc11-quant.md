# codeq 1.0.0rc11 Quant performance baseline

Date: 2026-08-29

Method: `benchmarks/quant_benchmark.py`, three measured runs per query against
`~/Quant`. Each cold sample creates and closes a fresh `Workspace`; warm samples
reuse one workspace after a complete workload warmup pass. Symbol context uses the
new provenance-labelled test discovery by default.

| Query | Cold P50 | Cold P95 | Warm P50 | Warm P95 |
| --- | ---: | ---: | ---: | ---: |
| find exact | 2549.1 ms | 2814.5 ms | 152.8 ms | 187.1 ms |
| find concept | 1234.5 ms | 1341.2 ms | 1013.4 ms | 1287.5 ms |
| context symbol | 4361.1 ms | 4500.5 ms | 1061.2 ms | 1120.5 ms |
| context reference store | 3725.2 ms | 3726.2 ms | 973.3 ms | 997.7 ms |
| context cursor | 4024.9 ms | 4356.2 ms | 911.6 ms | 930.7 ms |
| context + lexical | 4049.1 ms | 4085.9 ms | 1112.0 ms | 1112.7 ms |
| trace incoming depth 2 | 3535.4 ms | 3651.3 ms | 389.1 ms | 448.4 ms |
| exact text | 149.8 ms | 161.6 ms | 155.7 ms | 156.1 ms |
| review `HEAD~1` | 26.2 ms | 34.8 ms | 22.7 ms | 22.8 ms |
| broad review `HEAD~4` | 2052.2 ms | 2095.6 ms | 86.3 ms | 88.6 ms |

All samples returned `status=ok`. The readiness gate passed: warm context stayed
below 3000 ms, cold context below 5000 ms, and no representative semantic sample
reached 10000 ms. Expanded test discovery raises warm context work because it adds
bounded import and exact-test-text evidence; focused `context --section` requests
avoid unrelated sections when that cost is unnecessary.

The full machine-readable samples, including LSP/cache/prewarm deltas and phase
timings, are in [`results/1.0.0rc11-quant.json`](results/1.0.0rc11-quant.json).
