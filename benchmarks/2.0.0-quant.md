# CodeQ 2.0.0 Quant end-to-end acceptance

The release binary was measured for three cold and three warm runs per case on
Quant revision `ba4a5d62cf94a9180bafc61107fe156bca93a7c2`. Cold cases use
one-shot execution; warm cases reuse one private 2.x daemon. The runner enforces
a 15-second per-case hard limit and verifies that no process carrying its
private runtime survives cleanup.

| Query | Cold P50 | Cold P95 | Warm P50 | Warm P95 |
| --- | ---: | ---: | ---: | ---: |
| find exact | 482.2 ms | 507.4 ms | 219.6 ms | 227.8 ms |
| find concept | 273.2 ms | 283.9 ms | 34.0 ms | 43.0 ms |
| context symbol | 3612.2 ms | 3677.0 ms | 398.2 ms | 409.8 ms |
| context reference store | 1698.0 ms | 1700.8 ms | 603.6 ms | 634.1 ms |
| context cursor | 3589.4 ms | 3770.9 ms | 353.0 ms | 358.6 ms |
| context + lexical | 3749.4 ms | 3878.7 ms | 515.1 ms | 522.3 ms |
| trace incoming depth 2 | 3947.2 ms | 3975.3 ms | 419.1 ms | 428.5 ms |
| exact text | 149.0 ms | 149.8 ms | 153.2 ms | 157.4 ms |
| focused review | 3282.9 ms | 3327.7 ms | 69.8 ms | 87.2 ms |
| broad review | 8560.3 ms | 9524.5 ms | 950.6 ms | 1203.8 ms |

Every sample returned `status=ok`; the maximum representative semantic/review
sample was 9,524.5 ms, below the existing 10-second hard limit. The separate
peak RSS measurements were 17,840 KiB for a Rust query process, 29,660 KiB for
the Rust daemon, and 3,805,780 KiB for external language-server process trees.
The result supports the rewrite rationale—small native orchestration and clear
ownership—but does not misattribute language-server memory to Rust.

The release executable is 6,702,928 bytes (2,771,398 bytes with gzip). Across
25 same-host `codeq --version` probes, median startup was 2.649 ms for 2.0.0
versus 49.381 ms for the independently installed RC13 oracle. This is a startup
and distribution measurement, not a substitute for the end-to-end semantic
latencies above.

The committed agent workflow replay exercised all four public commands: 11/11
queries passed and 11/11 exposed command-specific actionable output. The Rust
release gate also preserved the anonymized 100-workflow mapping (93.3% direct or
approximate coverage), 0/50 unsupported navigation fallbacks, 30/30 frozen
query validations, and the agent-utility artifact's explicit non-causal claim
boundary.
