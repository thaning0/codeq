# codeq 1.0.0rc6 Quant performance baseline

Date: 2026-08-28

Method: `benchmarks/quant_benchmark.py`, two measured runs per query against
`~/Quant`. Each cold sample creates and closes a fresh `Workspace`; warm samples
reuse one workspace after a complete workload warmup pass. The broad-review case
uses `HEAD~4` (28 changed files in this run) to reproduce the scale of the
post-RC6 Agent-session outlier.

| Query | Cold P50 | Cold P95 | Warm P50 | Warm P95 |
| --- | ---: | ---: | ---: | ---: |
| find exact | 430.4 ms | 432.4 ms | 159.3 ms | 180.7 ms |
| find concept | 1062.2 ms | 1074.6 ms | 1253.0 ms | 1621.3 ms |
| context symbol | 3753.4 ms | 3950.4 ms | 327.1 ms | 362.2 ms |
| context reference store | 3380.8 ms | 3452.1 ms | 632.4 ms | 675.1 ms |
| context cursor | 3157.8 ms | 3242.7 ms | 147.4 ms | 152.2 ms |
| context + lexical | 3209.4 ms | 3231.7 ms | 315.4 ms | 339.0 ms |
| trace incoming depth 2 | 3551.8 ms | 3557.1 ms | 396.2 ms | 410.1 ms |
| exact text | 150.9 ms | 151.8 ms | 147.1 ms | 155.1 ms |
| review `HEAD~1` | 34.5 ms | 40.8 ms | 25.4 ms | 27.1 ms |
| broad review `HEAD~4` | 7447.0 ms | 7476.3 ms | 3167.7 ms | 3243.3 ms |

All samples returned `status=ok`. The maximum representative semantic/review
sample was **7476.3 ms**, below the readiness requirement of 10000 ms.

Phase diagnostics show where the live-shaped cost lands:

- cold complex context: roughly 2.4 s resolution, 64-67 ms prewarm, and
  0.86-0.98 s semantic-neighborhood analysis;
- cold broad review: 34-37 ms change discovery and 7.38-7.44 s review analysis.

The full machine-readable samples, including LSP/cache/prewarm deltas and phase
timings, are in [`results/1.0.0rc6-quant.json`](results/1.0.0rc6-quant.json).
